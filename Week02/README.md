# Nexora Technologies — Enterprise Infrastructure Plan

## Project Overview

Prepared as a Junior System Administrator for Nexora Technologies, a software development startup with 20 employees across four departments. This project focuses on designing the company's complete IT infrastructure from scratch before equipment deployment.

## Learning Objectives

- Analyze organizational IT requirements
- Prepare professional hardware, software, and network inventories
- Design a logical enterprise network topology
- Research system administration roles and responsibilities
- Create professional technical documentation using Markdown

## Company Scenario

Nexora Technologies is a newly established software development company with 20 employees. The company has no existing computers, server, network, internet infrastructure, or security policies, so the infrastructure must be planned from the ground up.

## Hardware Inventory Summary

The proposed infrastructure includes 20 workstations, consisting of 15 desktop computers and 5 laptops, along with a server, NAS storage, network switches, UPS units, wireless access points, a printer, and monitors. The equipment is planned to support the company's current operations while allowing room for future growth.

## Software Inventory Summary

The proposed software environment includes Windows 11 Pro for workstations, Ubuntu Server for the server environment, Microsoft 365 for business productivity, and free/open-source developer and utility tools needed for daily operations and technical work.

## Network Diagram

The network topology shows the Internet connection, ISP modem, Gigabit Router + Firewall, 24-port switch, server, NAS storage, network printer, wireless access points, and the four departments: IT, HR, Finance, and Sales.

## Technologies Used

- Draw.io / diagrams.net — network topology design
- Microsoft Word — project documentation
- Markdown — technical documentation
- GitHub — version control and portfolio hosting

## Challenges Encountered

One of the main challenges was balancing performance, reliability, and cost for a startup environment. Another challenge was designing a network that is simple enough to maintain while still allowing room for future expansion.

## Reflection

This project taught me that thorough planning is an important part of infrastructure deployment. Understanding what the business actually needs helps prevent wasted resources and future problems. Good infrastructure is not about buying the most expensive equipment; it is about choosing the right tools that fit the company's requirements and budget.
